# FILM LANE C · BIRTHS & RITES — the plates

Every plate is a REAL-TIME capture: `gaia.director.play({ audio:false, speed:1 })`
rolling the film's own clock, shot as fast as the rig allowed (~4–5 fps, so
Δt ≈ 0.2 film-seconds between plates) and NAMED BY THE FILM CLOCK it was taken
at (`t108_87.png` = t=108.87s). Seek stills are in `seek/`.

Rig: Brave (Metal-3 WebGPU adapter, `--mute-audio`, own profile, CDP 9227) on
the lane's isolated stack (server 8426 / vite 5179, atlas-ops + quest-ops POSTed
to /op). chrome-headless-shell was abandoned for capture: no hardware adapter on
this box → SwiftShader → 0.1 fps, which cannot photograph a 25-second window.
